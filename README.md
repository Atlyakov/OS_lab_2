
Системные требования:

Установленный Python версии 3.14 или выше.

Запуск скрипта:

Скачайте файл с исходным кодом (например, lab2.py).

Откройте терминал (командную строку) в папке с файлом.

Выполните команду:

python lab2.py

Настройка параметров:

В блоке if __name__ == '__main__': внутри скрипта вы можете изменять размер матриц (MATRIX_SIZE), степень (p_power) и количество запускаемых процессов (PROCESSES).
