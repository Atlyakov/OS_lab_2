#  Многопоточное умножение матриц (Лабораторная работа по ОС)

Программа на Python для демонстрации параллельных вычислений, межпроцессного взаимодействия (IPC) и синхронизации процессов с использованием модуля `multiprocessing`.

---

##  Системные требования
* Установленный **Python** версии 3.14 или выше.



## Инструкция по запуску
* Скачайте файл с исходным кодом (lab2.py).
* Откройте терминал (командную строку) в папке с файлом.
* Запустите скрипт командой: python lab2.py


## Настройка параметров
* В блоке if __name__ == '__main__': внутри скрипта вы можете гибко настраивать параметры экспериментов:
* MATRIX_SIZE — размерность квадратных или треугольных матриц.
* p_power — степень для возведения матрицы (задание на «5»).
* PROCESSES — количество запускаемых процессов (T).
