#  Многопоточное умножение матриц (Лабораторная работа по ОС)

Программа на Python для демонстрации параллельных вычислений, межпроцессного взаимодействия (IPC) и синхронизации процессов с использованием модуля `multiprocessing`.

---

##  Системные требования
* Установленный **Python** версии 3.14 или выше.
